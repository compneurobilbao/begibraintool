Vision reveals what the brain hides.

BegiBrainTool is a modular visual assessment battery for early detection and monitoring of Alzheimer's and Parkinson's disease — built on PsychoPy, open-source, and designed for both research and clinical environments.

Test Battery

Three modules.
One complete picture.

Each module targets a distinct dimension of visual processing, together forming a comprehensive assessment of vision-brain connectivity in neurodegenerative disease.

👁
Module 01

Spatial Vision

Evaluates basic and semantic visual processing through stimuli that systematically vary along three perceptual axes, with individual threshold calibration for each.

Spatial Frequency Contrast Color Saturation Threshold Detection
🎯
Module 02

Dynamic Vision & Eye Tracking

Analyzes visual attention, tracking ability, and oculomotor control through a suite of moving stimuli tasks synchronized with a GazePoint GP3 HD eye-tracker.

Fixation Stability Smooth Pursuit Saccades Flicker Fusion Visual Search
💓
Module 03

Autonomous Response

Measures unconscious physiological reactions to basic and emotionally charged visual stimuli via multi-modal biometric acquisition, capturing what the eye alone cannot reveal.

Pupillometry HRV GSR Emotional Stimuli
Motivation

Why vision?
Why now?

The retina is a direct extension of the brain. Changes in visual processing — saccades, fixation stability, pupil dynamics — emerge years before cognitive symptoms in Alzheimer's and Parkinson's.

🔍
A gap in clinical neuroscience No comprehensive toolbox exists today that evaluates vision specifically for early detection of neurodegenerative diseases.
📈
Growing clinical need The aging population in Spain and worldwide demands fast, non-invasive, and personalized screening tools.
🧩
Modular and adaptable Run only the tests you need. Designed for multicenter and longitudinal studies with JSON/XLSX parameter configuration.

Get Started

Up and running in minutes

Three steps to deploy BegiBrainTool in your lab or clinical environment.

🐍 Python 3.8+ 🧪 PsychoPy 2024+ 👁 GazePoint GP3 HD (recommended) 🪟 Windows (tested)
1
Clone the repository
# Clone via HTTPS
git clone https://github.com/compneurobilbao/begibraintool.git
cd begibraintool
2
Install dependencies
# Using PsychoPy's Python interpreter
C:\Program Files\PsychoPy\python.exe -m pip install -r requirements.txt

# Or via the PIP terminal in PsychoPy:
# Tools → Plugin/Packages Manager → Open PIP terminal
pip install -r requirements.txt
3
Launch the toolbox
python begibraintool_main.py
